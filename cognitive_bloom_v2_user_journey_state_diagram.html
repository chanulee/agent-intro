다이어그램 탐색 가이드

캔버스의 각 노드(검정 박스·마름모·알약·사각형)를 클릭하면 해당 단계의 사용자 행동, Pond/Garden 기기 반응, 설계 근거, Gemma 백엔드 처리 방식이 이곳에 표시됩니다.

v1 → v2 핵심 업데이트 요약

  • 01. 고정 4영역 → 가든 ASCII 텍스트 트리: 터치스크린에서 어제 이어가던 줄기를 선택하거나 새 줄기를 틔우면 폰드가 빛나며 세션을 시작합니다.
  • 02. 로딩 침묵 → 10초 심호흡 파티클: 전사 및 키워드 추출 시간을 파티클 호흡 리추얼로 치환해 날것의 감정에서 한 걸음 물러나게 합니다.
  • 03. 질문 중 단어 탭 → 발화 후 키워드 선택: 사용자 발화에서 추출된 핵심 키워드·뉘앙스를 먼저 선택한 뒤, Gemma가 반환하는 질문과 사고 깊이(%)를 따라 2–3턴 심화합니다.
  • 04. 역질문 & 원문 기반 시간축 연결: 세션 중 1회 정반대 가능성을 묻고, 기존 브랜치일 경우 지난번 자신의 한 문장 원문을 띄워 오늘과 비교합니다.
